# 동네U

> **대전·충청권의 동네 가게와 사용자를 AI로 연결하는 로컬마켓 활성화 서비스**

## 📌 프로젝트 소개

**동네U**는 충청도 말투인 **“동네유~”**의 친근한 어감과,  
**동네 + You**라는 의미를 함께 담은 이름입니다.

동네U는 사용자의 **위치, 예산, 시간대, 상황**에 맞는 대전·충청권 로컬 가게를 추천하고,  
소상공인에게는 **AI 홍보도우미**를 제공해 지역 골목상권 방문을 유도하는 서비스입니다.

---

## 🎯 선택 주제

**경제: AI 기반 대전·충청권 로컬마켓 활성화 방안**

---

## 🧩 문제 정의

대전·충청권에는 좋은 로컬 가게가 많지만, 소비자는 보통 배달앱이나 지도앱의 광고 상위 노출, 리뷰 수, 프랜차이즈 중심 추천에 의존합니다.

그 결과 작은 소상공인 가게는 발견되기 어렵고, 소비자도 매번 비슷한 선택지만 보게 됩니다.

또한 소상공인은 홍보글, 메뉴 설명, SNS 문구를 직접 작성하기 어렵고, 광고비를 내지 않으면 플랫폼에서 노출되기 힘듭니다.

동네U는 이 문제를 해결하기 위해 소비자에게는 **상황 기반 로컬 가게 추천**을 제공하고, 소상공인에게는 **AI 홍보 도구**를 제공합니다.

---

## 💡 핵심 아이디어

동네U는 단순한 맛집 추천 앱이 아닙니다.

기존 배달앱이나 지도앱처럼 사용자가 직접 검색하고 많은 목록 중에서 고르는 방식이 아니라,  
사용자의 현재 상황에 맞춰 **동네 로컬 가게 3곳을 압축해서 추천하는 서비스**입니다.

또한 소상공인에게는 메뉴명, 가격, 특징 같은 최소 정보만 입력해도  
AI가 홍보 문구, 메뉴 설명, SNS 문구를 생성해주는 기능을 제공합니다.

---

## ✅ 핵심 해결 방향

1. 소비자의 “오늘 뭐 먹을까?” 고민을 줄입니다.
2. 광고가 아닌 위치, 예산, 상황, 로컬성을 기준으로 가게를 추천합니다.
3. 너무 많은 검색 결과 대신 추천 카드 3개로 선택지를 압축합니다.
4. 공공데이터를 활용해 대전·충청권 로컬 가게 후보를 구성합니다.
5. 소상공인에게 AI 홍보도우미를 제공해 홍보 부담을 줄입니다.
6. 착한가격업소, 전통시장, 한산한 시간대 등 지역 상권 활성화 요소를 추천에 반영합니다.

---

## 👤 사용자가 동네U를 써야 하는 이유

사용자는 정보가 부족해서 메뉴를 못 고르는 것이 아니라, 선택지가 너무 많아서 고르지 못합니다.

동네U는 사용자가 직접 검색어를 고민하지 않아도, 현재 상황만 입력하면 적합한 동네 가게 3곳을 추천합니다.

### 사용자 장점

- 검색어를 고민하지 않아도 됩니다.
- 광고 상위 노출보다 상황 기반 추천을 받을 수 있습니다.
- 추천이 3개만 나와서 빠르게 결정할 수 있습니다.
- 프랜차이즈가 아닌 숨은 동네 가게를 발견할 수 있습니다.
- 예산, 위치, 시간대, 혼밥/친구/데이트 같은 상황이 반영됩니다.
- 착한가격업소나 가성비 좋은 가게를 찾기 쉽습니다.
- 친구들과 메뉴를 고를 때 합의가 쉬워집니다.

---

## 🧑‍🍳 사장님이 동네U를 써야 하는 이유

소상공인은 좋은 가게를 운영하고 있어도 홍보에 어려움을 겪습니다.

동네U는 사장님이 메뉴명, 가격, 특징만 입력해도 AI가 자연스러운 홍보 문구를 만들어줍니다.

### 사장님 장점

- 메뉴명, 가격, 특징만 입력하면 AI가 홍보 문구를 만들어줍니다.
- SNS 문구, 앱 소개글, 메뉴 설명, 해시태그를 쉽게 만들 수 있습니다.
- 한산한 시간대 타임딜 문구를 생성할 수 있습니다.
- 홍보에 익숙하지 않은 소상공인도 쉽게 가게를 알릴 수 있습니다.
- 광고비 없이도 상황 기반 추천을 통해 노출 기회를 얻을 수 있습니다.

## 🔍 기존 서비스와의 차별점

| 구분 | 기존 배달앱/지도앱 | 동네U |
|---|---|---|
| 목적 | 주문, 배달, 검색 | 로컬 가게 발견과 방문 유도 |
| 추천 기준 | 광고, 리뷰 수, 검색어 | 위치, 예산, 상황, 로컬성 |
| 결과 방식 | 많은 목록 제공 | 추천 카드 3개 제공 |
| 사용자 행동 | 직접 검색 | 상황 입력 후 추천 |
| 소상공인 지원 | 광고 중심 노출 | AI 홍보도우미 제공 |

### 배민/요기요와의 차이

배민과 요기요는 주문과 배달 중심 플랫폼입니다.  
동네U는 주문이나 배달이 아니라, **지역 가게의 발견과 방문 유도**에 집중합니다.

### 네이버지도와의 차이

네이버지도는 사용자가 직접 검색어를 입력하고 많은 결과 중에서 선택해야 합니다.  
동네U는 사용자의 위치, 예산, 시간대, 상황을 바탕으로 추천 결과를 3개로 압축해 빠른 결정을 돕습니다.

---

## 🗂 공공데이터 활용 계획

동네U는 공공데이터를 활용해 로컬 가게 후보를 구성하고, 추천의 신뢰성을 높입니다.

| 데이터 | 활용 목적 |
|---|---|
| 소상공인 상가업소정보 | 대전·충청권 로컬 가게 후보 DB 구성 |
| 대전 음식점 정보 | 메뉴, 가격, 업종 정보 보강 |
| 착한가격업소 현황 | 가성비 추천 카드 구성 |
| 전통시장 데이터 | 로컬마켓 활성화 메시지 강화 |
| 인허가 현황 데이터 | 발표 자료의 상권 분석 근거 |

### MVP 우선 활용 데이터

1. 소상공인 상가업소정보
2. 대전 음식점 정보
3. 착한가격업소 현황

---

## 🤖 AI 활용 방식

동네U는 복잡한 머신러닝 모델을 직접 학습시키기보다는,  
공공데이터와 규칙 기반 점수 계산을 활용해 추천 후보를 선정합니다.

AI는 추천 후보를 직접 고르는 역할보다는,  
사용자가 납득할 수 있는 **추천 이유**와 사장님을 위한 **홍보 문구**를 자연어로 생성하는 역할을 맡습니다.

## 🧮 추천 점수 예시

| 항목 | 점수 |
|---|---:|
| 거리 적합도 | 20점 |
| 예산 적합도 | 20점 |
| 상황 적합도 | 20점 |
| 메뉴 선호도 | 15점 |
| 로컬 가게 여부 | 15점 |
| 착한가격업소 여부 | 10점 |

총점이 높은 가게를 상위 후보로 선정하고,  
그중 사용자에게 보여줄 추천 카드 3개를 구성합니다.

---

## 🃏 추천 카드 구조

동네U는 단순히 추천 1, 추천 2, 추천 3처럼 보여주지 않고,  
각 추천 카드에 역할을 부여합니다.

### 오늘의 동네픽

| 카드명 | 의미 |
|---|---|
| 가까워U | 현재 위치에서 가까운 로컬 가게 |
| 아껴U | 예산에 맞는 착한가격/가성비 가게 |
| 새로워U | 평소 검색으로는 잘 안 보이는 숨은 동네 가게 |
| 살려U | 한산한 시간대 방문을 유도하는 골목상권 추천 |

MVP에서는 이 중 3개를 선택해 보여줍니다.

예시 구성:

1. 가까워U
2. 아껴U
3. 새로워U
